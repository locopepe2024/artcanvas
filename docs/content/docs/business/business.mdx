# 商务合作

ArtCanvas 当前以开源协作为主，尚未设置公开的商务邮箱或商业授权渠道。

## 适合沟通的方向

- 私有化部署、内网部署和团队版落地。
- 定制画布节点、生成流程、素材管理或后台能力。
- 接入自有 OpenAI 兼容接口、模型渠道或提示词仓库。
- 围绕 AI 图片、视频、文本生成工作流做联合方案。
- 技术支持、交付咨询或联合方案评估。

## 建议提供的信息

- 你的业务场景和预期用户规模。
- 需要部署的环境、数据保存方式和安全要求。
- 需要接入的模型、渠道、支付或账号体系。
- 期望的交付范围、时间和预算区间。

## 联系方式

可以通过 GitHub Issue 提交不包含商业机密的合作意向，并请求维护者提供私密沟通方式。不要在公开 Issue 中提交合同、预算、客户数据或凭据。

ArtCanvas 包含来自上游项目的 AGPL-3.0 代码；任何闭源许可都需要确认相关代码的完整版权授权，本仓库不会默认承诺可以对全部上游代码进行商业再许可。

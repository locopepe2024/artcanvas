## Direct implication

- Canvas 当前已经运行包含 UniArt 视频能力唯一 owner 逻辑、Provider adapter 和视频播放代理的新版本。
- Canvas 不再需要通过模型名称推断 H3/Seedance 的比例、输入类型、参考素材数量或可选字段。
- 旧版本仍可通过停止新容器、恢复 Nginx 备份并启动旧容器回滚。

# 视频任务查询契约

## 已观察事实

- 视频任务创建成功后，上游任务可以继续运行数分钟。
- 单次查询可能因为网络、限流、网关 5xx 或供应商暂时未返回 task data 而失败。
- 单次查询失败不等于视频任务进入失败终态。

## 契约

- 只有查询响应明确返回 `failed`、`cancelled` 或 `expired` 时，前端才把任务标记为失败。
- 网络错误、408/409/425/429、5xx、暂时缺少 task data 等可恢复查询错误应退避重试。
- 401/403、明确的请求参数错误及任务终态错误继续直接报告，不无限重试。
- 视频创作台和画布视频节点必须使用同一套等待逻辑。
- 任务详情已提供 `metadata.url`、`video_url`、`result_url` 或等价结果 URL 时，应直接读取该 URL，不再依赖跨域 `/content` 下载接口。
- 任务详情已提供结果 URL 后，远程视频下载和浏览器本地缓存属于可选后处理；该后处理必须有明确等待上限，失败或跨域受限时直接保留远程 URL，不能阻塞任务进入成功终态。
- 同一条生成记录进入终态时，记录列表、当前预览和结果区必须同步更新，不能保留终态记录与“生成中”预览并存的状态。
- OpenAI 兼容任务详情因旧任务响应转换失败而返回 5xx 时，前端应查询同一服务已有的 `/v1/video/generations/:task_id` 持久任务记录；该记录明确为 `SUCCESS` 或 `FAILURE` 时必须收敛到对应终态，不能继续把已完成历史任务无限重试为“生成中”。
- 用户主动停止任务时立即终止本地查询。

## 成功标准

1. 服务端任务仍为 running 时，单次查询失败不会把画布节点或创作台记录写成失败。
2. 查询恢复后继续使用原 task ID，不重复创建收费任务。
3. 服务端明确失败时仍及时显示实际失败原因。
4. 验证不创建新的付费视频任务。
5. 结果 URL 可用但跨域下载失败或长时间无响应时，界面仍在有限等待后显示成功结果。
6. 历史任务的 OpenAI 格式转换接口持续 5xx、但持久任务记录已为终态时，刷新页面后记录能够完成对账并停止轮询。

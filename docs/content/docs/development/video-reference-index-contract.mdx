# 视频参考素材索引契约

## 已观察事实

- ArtCanvas 视频请求按图片、视频、音频的顺序追加参考素材。
- UniRoute 的 Seedance 转换同样把来源素材拆成 `imageUrls`、`videoUrls`、`audioUrls`，并原样转发提示词。
- 旧版界面使用 `图片1`、`视频1`、`音频1` 三套独立编号，不能唯一表达合并后素材列表中的位置。

## 契约

视频生成统一使用从 1 开始的全局位置索引 `@n`：

1. 图片排在最前，并保留图片列表内的顺序。
2. 视频排在全部图片之后，并保留视频列表内的顺序。
3. 音频排在全部图片和视频之后，并保留音频列表内的顺序。

例如两张图片、一个视频和一个音频依次对应 `@1`、`@2`、`@3`、`@4`。首尾帧仍显示角色名称，但同时显示对应的 `@1`、`@2`。

画布组装提示词保存稳定的节点引用 token；发送前只选择提示词实际引用的素材，再按上述顺序重新生成 `@n`，避免删除或遗漏某个引用后出现索引空洞。

## 成功标准

1. 视频创作台素材角标、提示词说明和请求素材顺序一致。
2. 画布视频节点的引用选择、提示词序列化和请求素材顺序一致。
3. 图片、视频、音频混合时使用一套连续的 `@n`，不再按类型分别从 1 开始。
4. 同类型素材重新排序后，界面和最终请求中的索引同步更新。
5. 不修改 UniRoute，也不通过付费视频任务验证。
